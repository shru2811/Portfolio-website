# Shruti Srivastava — Portfolio

A single-page portfolio built with vanilla HTML, CSS, and JavaScript.

## Open locally

Open `index.html` in a browser. No installation or build step is required.

## Project structure

```
.
├── index.html        # Content and page structure
├── styles.css        # Core visual system and responsive layout
├── overrides.css     # Recent additions and easy custom styling
├── script.js         # Loading, scroll reveals, and theme toggle
└── assets/
    ├── images/       # Project and honours photographs
    └── icons/        # Optional social/site icons
```

## Personalise before publishing

- Replace every `href="#"` in `index.html` with the correct project, patent, and social URLs.
- Replace `your.email@example.com` with your email address.
- Add honours photos in `assets/images/`, then replace each gallery placeholder with an `<img>` tag.
- Replace the three project title placeholders, metadata, and visual blocks with your actual work.

## Publish

This can be deployed as-is on GitHub Pages, Netlify, or Vercel: upload the entire folder and select `index.html` as the entry point.
