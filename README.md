# Shruti Srivastava | Portfolio

Personal portfolio website for Shruti Srivastava, Software Engineer I at Dell Technologies. It brings together selected software and AI work, patents, professional experience, achievements, and ways to get in touch.

## Explore the portfolio

Use the navigation at the top of the page to move between the main sections:

- **Work** - Expand each project to learn about Acoustic Shield, Krishisaarthi, and Analyza, including their goals and technologies.
- **Experience** - View Shruti's journey at Dell Technologies and in student leadership.
- **Honours** - Browse a small collection of meaningful milestones and recognitions.
- **Socials** - Visit LinkedIn, GitHub, YouTube, and Instagram through the external links.
- **Contact** - Send an email directly from the final section of the page.

The theme button in the header switches between light and dark modes. Your preference is saved in the browser for future visits. Project and patent cards can be opened to reveal more detail, and the site is designed to work across desktop and mobile screens.

## Featured work

- **Acoustic Shield** - A bio-acoustic AI system for detecting potential wildlife-conservation threats from environmental audio.
- **Krishisaarthi** - An AI-powered crop advisory platform that helps farmers make data-informed decisions.
- **Analyza** - A conversational platform that turns CSV data and plain-language questions into insights and visualisations.

The portfolio also highlights work on an AI-IoT enabled hydro-powered water-quality monitoring system and the ongoing Acoustic Shield patent.

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

There is no build process or dependency installation required. Open `index.html` in a modern browser to view the site locally.

## Project files

```text
index.html     Page content and structure
styles.css     Core styling and responsive layout
overrides.css  Additional visual refinements

```
